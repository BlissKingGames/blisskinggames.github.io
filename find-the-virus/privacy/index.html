다른 이용자에게 보이는 정보

랭킹과 프로필에서는 닉네임, 선택 국가, 현재 아바타·사진 썸네일, 등급과 순위·기록이 다른 이용자에게 표시될 수 있습니다.

다른 사람의 사진이나 개인정보를 허락 없이 등록하지 마세요. 사진 등록을 원하지 않으면 게임에서 제공하는 기본 아바타를 이용할 수 있습니다.

사진 선택 과정에서 선택한 이미지를 읽고 게임용 복사본을 생성합니다. 운영자가 장치의 사진 보관함 전체를 일괄 업로드하지 않습니다.

신고와 차단 목록 자체를 공개 랭킹에 표시하지 않습니다. 운영자는 신고 검토를 위해 신고 시점의 프로필 내용과 관련 자료를 확인할 수 있습니다.

장치 저장, 개인 데이터 백업과 복원

상세 플레이 이력과 등록 사진 목록은 기본적으로 장치에 저장합니다. 현재 공개 프로필, 랭킹과 구매 권한 등 온라인 서비스 정보는 서버 저장 대상입니다.

개인 데이터 백업을 신청하면 해당 시점의 플레이 이력·진행도·등록 사진 등을 임시 서버 백업으로 저장합니다. 일반 백업 코드의 유효기간은 발급 후 7일입니다.

복원이 서버에서 승인된 뒤 미완료 상태가 되면 원래 만료 시각과 최초 복원 승인 후 72시간 중 늦은 시각을 재시도 기한으로 사용합니다. 재시도를 반복해도 이 기한이 계속 늘어나지는 않습니다.

복원 완료 시 코드는 사용 완료 처리됩니다. 완료·만료·취소되거나 교체된 백업의 정리는 서버의 삭제 처리 대상이며, 주기적 정리와 오류 재처리에 따라 실제 저장소 정리 시점에는 차이가 생길 수 있습니다.

백업은 신청 이후 변경 내용을 자동 포함하지 않습니다. 인증 비밀정보와 구매 권한은 장치 백업으로 이전하지 않으며 서버에서 다시 확인합니다.

새 장치로 복원을 승인하면 기존 설치의 온라인 접속이 해제됩니다. 기존 장치의 로컬 파일을 원격으로 삭제하는 기능은 아닙니다.

백업 없이 앱을 삭제하거나 장치 데이터를 지우면 장치 전용 기록·사진을 복원하지 못할 수 있습니다. 서버 계정 재연결과 개인 데이터 백업 복원은 서로 다른 절차입니다.

서비스 제공업체와 국외 처리

온라인 인증, 데이터 저장, 서버 기능과 랭킹에는 Unity Gaming Services를 사용합니다. Android 플랫폼 로그인, 스토어 결제와 환불에는 Google Play Games 및 Google Play를 사용합니다.

서비스 과정에서 관련 식별자, 프로필, 플레이·구매·백업·신고 데이터가 해당 기능을 제공하는 사업자에게 전송되거나 저장됩니다. 이용자가 고객지원 이메일을 보내면 Google의 이메일 서비스를 통해 문의 내용이 처리됩니다.

Unity 개인정보처리방침과 Google 개인정보처리방침에서 각 사업자의 데이터 처리 내용을 확인할 수 있습니다.

Unity의 일반 서비스 약관과 개인정보 처리 부속계약에는 처리 사업자로 Unity Technologies S.F.가 기재되어 있습니다. 개인정보 문의 연락처는 DPO@unity3d.com입니다. Unity 개인정보 처리 부속계약과 재수탁자 안내에서 공개된 내용을 확인할 수 있습니다.

이 홈페이지는 GitHub Pages를 이용합니다. GitHub는 홈페이지 방문자의 IP 주소를 보안 목적으로 기록하며, 이용자가 GitHub에 로그인했는지와 관계없이 적용됩니다. GitHub Pages 안내와 GitHub 개인정보처리방침을 참고해 주세요.

이 홈페이지 자체에 별도의 방문 분석 도구, 광고 추적 도구나 개인정보 입력 양식을 추가하지 않았습니다. 이메일 링크로 문의하면 이용자의 이메일 프로그램에서 메일을 작성하며 홈페이지가 문의 내용을 별도 저장하는 방식은 아닙니다.

공개 전 확정 항목실제 계약상 수탁자와 연락처, 국외 처리 국가, 이전 항목·목적·시기·방법·보관기간 및 적용 근거·거부 방법을 서비스별로 확인하여 이 절에 기재합니다. 제공업체의 전 세계 처리 가능 국가 목록을 이 게임의 확정 저장 위치로 단정하지 않습니다.

보관기간과 삭제

앱 삭제는 서버 계정과 모든 관련 서버 데이터의 삭제를 뜻하지 않습니다. 백업 취소·만료, 프로필 차단, 계정 정지와 계정 삭제도 각각 다른 처리입니다.

전자적 정보는 복구하기 어렵도록 삭제하는 방식으로 처리하고, 보존이 필요한 정보는 서비스에서 계속 사용하는 정보와 구분해야 합니다.

문의에는 게임 이름과 요청 내용을 기재해 주세요. Google 비밀번호, 인증 토큰이나 백업 복원 코드를 이메일로 보내지 마세요.
